### Column reference

Legend for columns in the **Summary** table (index documentation — not an epic).

| Column           | Meaning                    | How to obtain / rule                                                                                                                                                                                                                                                                             |
| ---------------- | -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **ID**           | Stable identifier          | Inception: `i-<L>` from `.epic-i<L>_<slug>.md` (**EPICS-24**); prioritization: `<N>-<L>` from `.epic-<N>-<L>_<slug>.md`; implementation / closed: `EPIC-NN`; cancelled: corresponding `EPIC-NN`, `i-<L>`, or `<N>-<L>` from `cc.epic-*` (**EPICS-05**, **EPICS-25**, **EPICS-27**, **EPICS-28**) |
| **Slug**         | Epic file suffix           | kebab-case; after inception letter or after `0-` in root filename                                                                                                                                                                                                                                |
| **Status**       | Plan lifecycle             | `injection` \| `pending` \| `in_progress` \| `paused` \| `pull_request` \| `done` \| `cancelled` — **EPICS-26**                                                                                                                                                                                  |
| **Mids**         | Step progress              | `<completed>` / `<total>` — from the **Step Summary** table inside the epic                                                                                                                                                                                                                      |
| **Date-Init**    | Entry to version control   | `YYYY-MM-DD` of the first commit adding the plan file (`git log --follow --diff-filter=A`)                                                                                                                                                                                                       |
| **Date-Release** | Published in main branch   | `YYYY-MM-DD` of the **PR** merge for the row; `—` if not yet merged                                                                                                                                                                                                                              |
| **Prior.**       | Operator priority          | `0` (urgent and necessary) … `100` (latest expected order); `—` if not prioritized, `done`, or `cancelled` (**EPICS-27**)                                                                                                                                                                        |
| **Impact**       | Anticipated SemVer + areas | `PATCH` \| `MINOR` \| `MAJOR` · `area1, area2` — summary from the **Impact** block of the epic                                                                                                                                                                                                   |
| **Branch**       | Working branch             | Canonical branch name for the epic; `—` until the branch exists                                                                                                                                                                                                                                  |
| **PR**           | Pull request               | Number or `—`                                                                                                                                                                                                                                                                                    |
| **Release**      | Delivered stable version   | Primary field from the manifest (`version:` or similar) after merge; `—` until then                                                                                                                                                                                                              |
| **Alpha**        | Initial ordering letter    | Original `<L>` from the initial `.epic-i<L>_<slug>.md` phase; preserve through prioritization, implementation, closure, and cancellation (**EPICS-24**, **EPICS-28**)                                                                                                                            |

* Note: `Prior.` is not deduced solely from `Date-Init` or `Impact`.
